# 🎬 Top Horror Movie Website

A feature-rich web application built with Python and Flask that lets users explore top-rated horror movies, add new movies to their personal library, update ratings and reviews, and fetch details dynamically using an external movie database API.

---

## 🚀 Features

- **Browse Top Movies:** View a curated collection of horror movies ranked by ratings and user reviews.
- **Add New Movies:** Search and add new horror titles to your watchlist directly through the platform.
- **Rate & Review:** Update ratings, edit personal reviews, and customize movie details.
- **Database Integration:** Utilizes SQLite and Flask-SQLAlchemy for robust data storage and persistence.
- **Clean UI:** Styled with Bootstrap for a responsive and modern user experience.

---

## 🛠️ Built With

- **Python** (Backend Logic)
- **Flask** (Web Framework)
- **Flask-SQLAlchemy** (Database & ORM)
- **Flask-Bootstrap** (Frontend UI styling)
- **SQLite** (Database storage)
- **HTML5 / CSS3**
